# 输入文本

- **指令标识**：`FillText`
- **指令类型**：网页指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/filltext/
- **平台搜索名称**：`输入文本`
- **说明**：在指定的网页元素中输入文本内容，支持多种文本生成和填充选项
- **必填输入参数**：`元素选择器`, `待填充文本`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 元素选择器 | String | 是 | - | 用于定位的页面元素的选择器，不能为空，支持从元素库选择元素或手动填写 XPath 等定位器值 |
| 待填充文本 | String | 是 | - | 固定内容：支持填写固定文本、引用变量、内置函数拼接文本规则 运行时AI生成：支持用户填写自然语言，运行时由AI按用户要求生成内容 |
| iframe页面定位器 | String | 否 | - | 用于定位iframe的表达式，非必填，如果目标元素在iframe中则需要填写，例如：//html/iframe |
| 定位超时时间 | Double | 否 | 5000 | 元素定位的最大等待时间，超时将停止等待，单位毫秒。默认值 5000ms ，设置为 0 表示不等待 |

## 配置要点

- **必填**：`元素选择器`、`待填充文本`（均带红色 `*`，未填时输入框红色边框）
- 粘贴 XPath → **按 Enter** 让 AntD Select 接受为定位器（`element-selector.md` §方式 C）
- **保存前**确认两项均无红框，再点弹框右下角「保存」

## XML 示例

```xml
<FillText    selector="//textarea[@id='chat-textarea']"    text="美团"    findElementOptions="{'timeout':5000}"/>
```
