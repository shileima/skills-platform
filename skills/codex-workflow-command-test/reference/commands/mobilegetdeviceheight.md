# 获取手机屏幕高度

- **指令标识**：`MobileGetDeviceHeight`
- **指令类型**：移动端指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/mobilegetdeviceheight/
- **说明**：获取当前移动设备屏幕高度

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 将结果保存至 | String | 否 | - | 填写变量名称，保存获取到的手机屏幕高度 |

## XML 示例

```xml
<MobileGetDeviceHeight outKey="output"/>
```
