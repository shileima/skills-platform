# 字符串拼接

- **指令标识**：`Concatenate`
- **指令类型**：通用指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/concatenate/
- **说明**：将多个字符串拼接成一个字符串
- **必填输入参数**：`字符串`
- **必填输出参数**：`将结果保存至`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 字符串 | List<String> | 是 | - | 待拼接的字符串，输入后回车形成字符串项，支持填多个 |

## 输出参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 将结果保存至 | String | 是 | - | 填写变量名称（ eg: result ），保存拼接后的字符串结果 |

## XML 示例

```xml
<Concatenate    stringList='["hello","world"]'    outKey="output"/>
```
