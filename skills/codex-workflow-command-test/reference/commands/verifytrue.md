# 验证条件为真

- **指令标识**：`VerifyTrue`
- **指令类型**：通用指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/verifytrue/
- **说明**：该指令用于验证数字关系、字符串包含、集合关系和空值
- **必填输入参数**：`左值`, `操作符`, `右值`
- **必填输出参数**：`将结果保存至`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 左值 | String | 是 | - | 需要进行验证的值 |
| 操作符 | String | 是 | - | 需要验证的条件 |
| 右值 | String | 是 | - | 等待进行验证比较的值。当操作符为’为空’、‘不为空’时，为非必填 |

## 输出参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 将结果保存至 | Boolean | 是 | - | 输出: 方法调用结果输出的变量名 |

## XML 示例

```xml
<VerifyTrue    leftValue="234"    operator="IS_EMPTY"    outKey="output"/>
```
