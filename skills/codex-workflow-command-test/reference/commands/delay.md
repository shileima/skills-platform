# 延迟

- **指令标识**：`Delay`
- **指令类型**：通用指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/delay/
- **说明**：工作流延迟执行
- **必填输入参数**：`延迟时间`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 延迟时间 | Double | 是 | - | 延迟时间，必须为正数，支持小数（ eg: 1.5 ），时间不能为空 |
| 时间单位 | Enum | 否 | SECOND | 时间单位，可选值: 秒 、 分钟 、 小时 、 天 ，不传默认为 秒 |

## 配置要点

- 弹框「常规」Tab → 「输入参数」区：**仅 `延迟时间` label 前有红色 `*`**，为必填
- `时间单位`、`是否发送消息` 无 `*`，非必填；时间单位默认「秒」
- **保存前**：确认「延迟时间」已填入正数（如 `1` 或 `1.5`），输入框**无红色边框**
- **禁止**在「延迟时间」为空时点击「保存」

## XML 示例

```xml
<Delay    second="10"    timeUnit="SECOND"/>
```
