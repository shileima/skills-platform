# 美团日程会议室预订

在 `calendar.sankuai.com/rooms` 按用户给定的日期、会议室名称和时间段预订会议室。

## 输入参数

| 参数 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `roomName` / 会议室名称 | 是 | 目标会议室 | `福鼎厅` |
| `date` / 日期 | 是 | 目标日期 | `今天`、`8月13日`、`2026-08-13` |
| `time` / 时间 | 是 | 目标时间段 | `08:00-09:30` |
| `location` / 地点 | 否 | 楼宇筛选，默认北京/融新大厦B座 | `北京/融新大厦B座` |
| `topic` / 主题 | 否 | 日程主题，可为空 | `项目沟通` |

## 主流程

1. 打开 Chrome，地址栏 `set_value` 到 `https://calendar.sankuai.com/rooms`，回车。
2. 选择目标日期：
   - 当前日期与目标日期不一致时，用日期左右箭头逐日切换；每次点击后 `ax.get(app,{refresh:true})` 校验日期文本。
   - 日期不可通过箭头稳定切到时，打开日期控件选择目标日期。
3. 选择地点：默认保持或选择 `北京/融新大厦B座`。
4. 清空楼层筛选：打开楼层筛选后优先点「重置」/「清空」再「确定」，避免因旧楼层条件漏掉目标会议室。只有用户明确指定楼层时才勾选楼层。
5. 分页找会议室：
   - 在当前页查找 `roomName`；找不到则按页码 `1,2,3...` 逐页点击。
   - 每次翻页后必须重新 `ax.get(app,{refresh:true})`，禁止复用旧 idx。
   - 找到目标会议室后记录它在当前页的列位置。
6. 定位并点击目标时间单元格：
   - 日程网格是「会议室横向排列、时间纵向排列」：会议室决定 `x`，时间决定 `y`。
   - 优先读取 macOS AX frame，计算 `x = roomName 文本中心 x`、`y = start/end 时间刻度之间的中点 y`。
   - 点击前必须确认目标格是白色可预订区域。
   - 点击后只出现会议室详情卡片，说明点到标题/详情区；重新采样坐标后再点时间格。
7. 弹框校验并修正：
   - 弹框必须包含「创建日程」、目标日期、`roomName`、地点楼宇、开始/结束时间。
   - 如果会议室/地点不对，关闭弹框，重新采样网格坐标点击。
   - 如果会议室/地点正确但时间不对，在弹框内修正开始/结束时间。
8. 可选填写主题。
9. 提交前再次校验日期、会议室、地点、开始时间、结束时间；无「冲突/不可/占用」提示后点击「完成」。
10. 点击后重新取树：弹框关闭且无错误提示才返回成功。

## 网格颜色语义

预订前必须识别时间网格颜色：

- **白色底色**：可预订时间段，允许点击。
- **灰色底色**：他人已预订时间段，禁止点击；如目标时间覆盖灰色区域，停止并告知不可预订。
- **蓝色底色**：本人已预订时间段；如果目标时间已被本人占用，停止并说明已有预订，不重复提交。

如果 AX 无法表达颜色，用截图/OCR 或视觉判断辅助；不能仅凭文字存在就点击。

## 时间单元格点击规则

1. 不要点 `roomName` 文本本身；那通常只打开会议室详情卡。
2. 不要点背景时间轴文本；那可能触发错误时间段或未保存确认。
3. 点击坐标必须来自当前页面最新布局：详情卡片、弹框、分页、滚动后旧坐标全部作废。
4. 点击后若弹框时间不等于目标时间，不提交，走「弹框时间修正」。

## 弹框时间修正

时间控件是滚轮/虚拟列表，不是普通输入框：

- 很多候选项在 AX 中只是 `AXStaticText`，`AXPress` 可能不生效。
- 不用 `set_value` 硬写时间按钮。
- 必须限定在弹框时间浮层区域内操作，过滤背景时间轴。

### 双列滚轮稳定步骤

当浮层 AX 类似：

```text
197 内容列表
  198 文本 13
  199 文本 14
  200 文本 15
210 内容列表
  211 文本 00
  212 文本 05
```

固定顺序：

1. 先在小时列点击目标小时，例如 `14`。
2. 等 300~800ms，重新 `ax.get(app,{refresh:true})`。
3. 重新定位分钟列目标值，例如 `00` 或 `30`，不要复用旧 index。
4. 再在分钟列点击目标分钟，例如 `00` 或 `30`。
5. 重新取树，校验弹框时间变为目标时间。
6. 如果目标小时不可见，只在小时列内部上下小幅滑动；如果目标分钟不可见，只在分钟列内部上下小幅滑动。禁止滚动整个页面。

成功经验：
- `13:45 → 14:00`：点小时 `14`，再点分钟 `00`，弹框变为 `13:00-14:00`。
- `09:00 → 09:30`：点小时 `09`，再点分钟 `30`，弹框变为 `08:00-09:30`。

### 连续时间候选列表

如果浮层显示 `13:35、13:40、13:45、13:50、13:55` 这类连续时间列表：

1. 目标 `14:00` 不可见时，只在红框候选列表内向下滚动。
2. 目标出现后点击红框内 `14:00`。
3. 禁止点击背景时间轴上的 `14:00`。

### AXPress 失效处理

1. 候选项是 `AXStaticText` 或 `AXPress` 非 success 时，不重试 AXPress。
2. 读取候选项 frame，限定浮层区域后用系统级坐标点击候选中心。
3. 点击后 `ax.get(app,{refresh:true})` 校验时间。
4. 若出现「本次编辑还未保存，确定退出吗？」说明点到弹框外，必须点「取消」回到弹框，不可点「确定」。

## 异常处理

- 未登录：提示用户完成登录后重试。
- 未找到会议室：报告当前日期/地点/楼层筛选和已扫描页数。
- 目标时间覆盖灰色区域：报告该时间段已被他人占用，不提交。
- 目标时间覆盖蓝色区域：报告本人已有预订，不重复提交。
- 弹框出现冲突、不可预订、必填项缺失：原样报告，不反复点击「完成」。
- 日期、会议室、地点、时间任一校验失败：停止，不提交。
