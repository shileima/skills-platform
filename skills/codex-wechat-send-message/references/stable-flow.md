# 微信发消息 — 快速稳定流程

基于实测成功路径，**固定坐标 + cliclick**，全程零 OCR 截图（单次截图 ~10s，已移除）。

## 原则

| 做 | 不做 |
|----|------|
| 固定相对坐标点击 | OCR 轮询 / 反复试错 |
| 聊天列表打开联系人 | 侧栏搜索（易误开搜一搜） |
| 一次粘贴 + 点发送 | 多次截图校验 |

## 坐标（窗口相对，基准 960×720）

| 步骤 | X | Y | 说明 |
|------|---|---|------|
| 聊天 Tab | 0.04 | 0.11 | 左侧导航 |
| 列表空白 | 0.18 | 0.22 | prepare 回到主界面 |
| 文件传输助手 | 0.18 | 0.28 | 测试联系人 |
| 业务联系人（如尹来春） | 0.18 | 0.21 | 最近聊天第 2 项 |
| 右侧聚焦 | 0.75 | 0.45 | 加载聊天窗 |
| 输入框 | 0.65 | 0.88 | 粘贴消息 |
| 发送按钮 | 0.88 | 0.93 | 绿色发送 |

## 流程（~5–8 秒）

```
prepare → open（双击列表 + 聚焦右侧）→ 点输入框 → 粘贴 → 点发送
```

### prepare（无截图）

1. 激活 + 标准化窗口
2. 点聊天 Tab → Esc×2 → Cmd+W → 点列表空白

### open

- **文件传输助手**：双击 `(0.18, 0.28)` → 聚焦 `(0.75, 0.45)`
- **业务联系人**：双击 `(0.18, 0.21)` → 聚焦 `(0.75, 0.45)`
- 联系人须在最近聊天列表对应行；可通过 `WECHAT_CONTACT_LIST_Y` 调整

### compose + send

1. 点输入框 → `pbcopy` + Cmd+V
2. 点 `(0.88, 0.93)` 发送

## 环境变量（可选）

| 变量 | 默认 | 说明 |
|------|------|------|
| `WECHAT_CONTACT_LIST_Y` | 0.21 | 业务联系人在列表中的 Y |
| `WECHAT_VERIFY` | 0 | 1=发送后 OCR 校验（慢） |
| `WECHAT_SEND_USE_OCR` | 0 | 1=OCR 定位发送按钮 |
| `WECHAT_SKIP_FINAL_SCREENSHOT` | 1 | 1=结果 JSON 不截图 |

## 入口

```bash
bash scripts/send-message.sh "<联系人>" "<消息>"
bash scripts/send-test-message.sh "<测试消息>"
```
