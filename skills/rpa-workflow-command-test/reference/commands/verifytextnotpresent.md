# 验证文本不存在

- **指令标识**：`VerifyTextNotPresent`
- **指令类型**：网页指令（"网页自动化 → 网页断言"分组）
- **平台指令名**：`验证文本不存在`（**不含 `(web)` 后缀**）
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/verifytextnotpresent/
- **说明**：验证指定文本**不**出现在当前页面 DOM/可见文本中
- **必填输入参数**：`待验证文本`
- **必填输出参数**：`将结果保存至`（默认为节点 ID）

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 待验证文本 | String | 是 | - | 页面中需要验证**不存在**的文本 |
| 是否为正则表达式 | Boolean | 否 | false | 是否将"待验证文本"作为正则匹配 |
| 定位超时 | Double | 否 | 5000 | 等待判定的最大时间（毫秒） |

## 输出参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 将结果保存至 | String | 是 | 节点 ID | 保存验证结果（true / false） |

## 平台搜索/双击定位

搜索框输入 `验证文本不存在` 后，AX Tree 上只出现单行 `X 文本 验证文本不存在`（非 `text ... (web)` 格式）。双击匹配行：

```js
const target = lines.find(l => /^\s*\d+\s+文本\s+验证文本不存在$/.test(l.trim()));
```

## 配置弹框字段

与 [verifytextpresent.md](verifytextpresent.md) 结构完全一致，唯一必填字段是 `* 待验证文本`（文本输入区）。

**测试用例建议**：填一个页面上肯定不存在的字符串，如 `NotExistText123XYZ`（ASCII、随机、无歧义）。

## 常见踩坑

| 现象 | 原因 | 处理 |
|------|------|------|
| 断言意外通过（返回 true） | 页面里巧合含该文本 | 换更随机的字符串（加时间戳/UUID 片段） |
| Cmd+V 中文粘贴 filled=false | 文本输入区 IME 冲突 | type_text ASCII |
