# 手机截屏

- **指令标识**：`MobileTakeScreenshot`
- **指令类型**：移动端指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/mobiletakescreenshot/
- **说明**：手机屏幕截图，保存至输出参数
- **必填输入参数**：`将结果保存至`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 将结果保存至 | String | 是 | - | 输出指令的截图保存结果信息 |

## XML 示例

```xml
<MobileTakeScreenshot outKey="output"/>
```
