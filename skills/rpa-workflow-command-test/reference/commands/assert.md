# 断言

- **指令标识**：`Assert`
- **指令类型**：通用指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/assert/
- **说明**：断言子节点输出是否满足失败条件，满足则终止工作流运行
- **必填输入参数**：`断言失败条件`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 断言失败条件 | Enum | 是 | - | 配置失败条件，断言内部子节点输出满足条件时，运行终止 |
| 失败提示信息 | String | 否 | - | 配置断言失败时日志输出的信息 |

## 输出参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 将结果保存至 | String | 否 | - | 存储结果的变量 |

## XML 示例

```xml
<Assert    assertFailCondition="EXISTS_FALSE"    message="断言失败"    outKey="output"/>
```
