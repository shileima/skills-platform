## 配置要点

- 弹框「常规」Tab → 「输入参数」区：**label 文字前的红色 `*`** 表示必填（无 `*` 通常非必填）
- 逐项填写所有带 `*` 的字段；**必填为空 → 禁止点「保存」**
- **保存前**：确认所有必填输入框**无红色边框**，内容已完整且非空
- 再点弹框右下角「**保存**」
