# 点击坐标

- **指令标识**：`MobileTapAtPosition`
- **指令类型**：移动端指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/mobiletapatposition/
- **说明**：在移动设备上点击指定坐标位置
- **必填输入参数**：`x`, `y`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| x | Integer | 是 | - | 点击位置的X坐标 |
| y | Integer | 是 | - | 点击位置的Y坐标 |

## XML 示例

```xml
<MobileTapAtPosition    x="100"    y="100"/>
```
