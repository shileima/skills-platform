# 验证相等

- **指令标识**：`VerifyEqual`
- **指令类型**：通用指令
- **官方文档**：https://document.waimai.st.sankuai.com/commands/ui-commands/verifyequal/
- **说明**：该指令用于验证两个数值是否相等，支持整数和小数的比较验证
- **必填输入参数**：`实际值`, `期望值`
- **必填输出参数**：`将结果保存至`

## 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 实际值 | Double | 是 | - | 需要进行比较验证的实际数值，实际值不能为空，仅支持数字类型, eg: 10 |
| 期望值 | Double | 是 | - | 与实际值进行比较的期望数值，期望值不能为空，仅支持数字类型, eg: 10 |

## 输出参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 将结果保存至 | String | 是 | - | 填写变量名称（ eg: equalResult ），保存验证结果（ true / false ） |

## XML 示例

```xml
<VerifyEqual    actualNumber="3"    expectedNumber="3"    outKey="output"/>
```
